# rbx-up-and-coming-forecast

Forecast for make.fun's roblox-up-and-coming-forecast-01: reads the Up-and-Coming chart history and writes, for each of the top ten places, a probability for each candidate game, plus a top-ten order.

## Run it

```
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 -P -s main.py
```
